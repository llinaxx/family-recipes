# Family Recipes

Сервис для хранения кулинарных рецептов семьи.

## Назначение

Приложение, в котором семья хранит свои рецепты: кто автор,
сколько готовить, к какой категории относится блюдо.
Можно добавлять рецепты, искать их по названию, смотреть по категориям,
отмечать избранное.

## Целевая аудитория

Семьи, которые хотят вести общую кулинарную книгу в цифровом виде,
чтобы рецепты не терялись и были доступны всем членам семьи.

## Предметная область

Домашняя кулинария. Учёт рецептов, категорий блюд и участников семьи.

## Основные сущности

- Семья (family)
- Участник (member)
- Рецепт (recipe)
- Категория (category)

## Классы проекта

### Family
Семья — группа пользователей с общими рецептами.
Атрибуты: `id`, `name`, `created_at`, `members`.
Методы: `add_member()`, `from_data()`, `to_data()`, `__str__()`.

### Member
Участник семьи.
Атрибуты: `id`, `name`, `role`.
Методы: `is_admin()`, `from_data()`, `to_data()`, `__str__()`.

### Category
Категория блюд.
Атрибуты: `id`, `name`, `description`.
Методы: `from_data()`, `to_data()`, `__str__()`.

### Recipe
Кулинарный рецепт.
Атрибуты: `id`, `title`, `author`, `category`, `cooking_time`, `difficulty`, `is_favorite`.
Методы: `is_quick()`, `mark_favorite()`, `from_data()`, `to_data()`, `__str__()`.

## Возможности

- просмотр списка рецептов;
- поиск рецепта по названию;
- фильтрация по времени готовки;
- сортировка по времени;
- статистика (всего рецептов, среднее время, избранные);
- просмотр семей;
- пометка рецепта как избранного;
- сохранение данных в JSON-файлы.
